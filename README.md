# Relatórios · Agência O2

Portal estático de relatórios de performance publicado via GitHub Pages.

## Estrutura

- `/` — landing page institucional com contato pelo WhatsApp.
- `/outplan/` — relatórios da Outplan.
- `/assets/` — recursos compartilhados da Agência O2.
- `/outplan/assets/` — recursos específicos da Outplan.

O repositório e o site são públicos. Não incluir credenciais, dados pessoais ou qualquer conteúdo que exija controle de acesso.
